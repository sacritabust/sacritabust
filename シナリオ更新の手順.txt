【シナリオを全端末に反映する手順（アプリで編集 → Git に置く）】
1. アプリのメニュー「シナリオの編集」で、お店の名前・問題・答え・コメントなどを直します（自動で保存されます）。
2. 編集画面の一番下「scenario.json を出力」の
   ・「コピーする」：中身をコピー
   ・「ファイルに保存」：scenario.json として保存／共有（iPhone では「ファイルに保存」やメール・AirDrop など）
   のどちらかを押します。
3. GitHub の scenario.json を開き、鉛筆アイコンで中身を全部貼り付け（または、ファイルを置き換えてアップロード）してコミットします。
4. 数分後、他の端末が次にアプリを開いたときに（ネット接続が必要）自動で反映されます。
   版番号 "rev" は出力のたびに自動で上がるので、手で変える必要はありません。

・出力した端末では、その時点で最新として扱われます。出力したら必ず Git に置いてください（置かないまま他端末で古い rev を上げると食い違います）。
・各スポットの "id" は変えないでください（進み具合とキーワードが引き継がれます）。
・スポットは最大 5 つです。
・曲の設定は、各端末のメニュー「サウンド」で行います（scenario.json には入りません）。
・scenario.json を直接直したい場合は、編集画面の「読み込み」に貼り付けて取り込むこともできます。

【曲（音楽）を GitHub に置いて設定する】
1. 曲のファイルを、GitHub の「music」フォルダにアップロードします（Add file → Upload files。フォルダが無ければ作ってください）。
2. アプリの「シナリオの編集」で、開始画面の曲・各スポットの曲・フィナーレの曲（虹の階段の画面から最後の画面まで）の「曲のファイル名」に、そのファイル名を入力します（例：start.m4a）。「試聴」で確認できます。
3. 「scenario.json を出力」でコピー／保存し、GitHub の scenario.json を置き換えます。
4. 他の端末は、次に開いたときに曲の設定と曲のファイルを取得します（ネット接続が必要。一度取得すると、その後はオフラインでも流れます）。
・同じファイル名で曲を差し替えた場合は、古い曲が残ることがあります。差し替えるときは、ファイル名も変えてください。
・GitHub にまだ置いていない曲は、「この端末のファイルを選ぶ」で、この端末だけで試せます。
